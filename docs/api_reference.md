# API Reference

## Endpoints
- GET /api/v1/health - Liveness probe
- POST /api/v1/data/upload/{project_id} - Document upload
- POST /api/v1/process/{project_id} - Document chunking
- POST /api/v1/nlp/search/{project_id} - Semantic search
- POST /api/v1/nlp/answer/{project_id} - RAG answer generation
